codex-auth can optionally call private ChatGPT endpoints for usage and workspace
metadata. CodexSwitch keeps this mode off by default and asks for explicit user
consent before each user enables it. The bundled implementation may place an
access token in a local Node process argument while the request runs. Upstream
warns that this behavior may violate terms of service and may create account
restriction or suspension risk.
